# Source every figure for a funder or the board

## Summary
Every dollar amount, headcount, date or percentage in a draft bound for a funder or the
board is checked against the current budget workbook or the signed agreement, and the
file and tab are named when the draft is handed over.

## Explanation
If the source cannot be found, the draft carries a visible `[UNVERIFIED]` marker where the
number would go, and Morgan is told. A figure that appears only in an older copy is flagged,
not used.
